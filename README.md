# Python Learning

This repository contains beginner-friendly Python examples, exercises, and assignments created while learning Python fundamentals.

## Contents

The [`python_learning`](python_learning) directory includes examples covering:

- Python basics: variables, data types, casting, operators, and input
- Strings and string operations
- Collections: lists, tuples, sets, and dictionaries
- Conditional statements, loops, nested loops, and pattern exercises
- Functions and function arguments
- Modules and importing code
- Object-oriented programming
- File handling

## Assignments

The practice assignments apply the concepts introduced in the examples:

- `Assignment1.py`: variables, printing, quotes, and formatting
- `Assignment2.py`: input, calculations, and dictionaries
- `Assignment3.py`: leap years, login checks, and eligibility logic
- `assignment4.py`: string formatting, slicing, and palindrome checks
- `assignment5.py`: loops, patterns, factorial, vowels, and Fibonacci
- `assignment6.py`: collection operations, comprehensions, and nested dictionaries

## Small Projects

- [`calculator.py`](python_learning/calculator.py): a basic calculator
- [`password_checker.py`](python_learning/password_checker.py): password validation practice

## Reference Material

The repository also contains a Python tutorial PDF used as supplementary learning material.

## Getting Started

1. Install Python 3.10 or newer.
2. Clone this repository and move into the project directory:

	```bash
	git clone <repository-url>
	cd Python_repo
	```

3. Run an example script:

	```bash
	python python_learning/first.py
	```

On Windows, use `py` instead of `python` if that is the command configured on your system.

## Learning Approach

Start with the fundamental examples, then work through the assignments and small projects. Most files are independent and can be run individually while experimenting with the code.

Several scripts request interactive input. The file-handling example also expects the files it reads to be available in its working directory.
